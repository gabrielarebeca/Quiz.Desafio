# 🎮 Quiz Desafio

Este repositório contém um projeto de **quiz interativo**, onde o usuário responde a uma série de perguntas e recebe uma pontuação com base nas respostas. O desafio visa demonstrar a implementação de lógica de quizzes em uma aplicação web simples.

## 📌 Sobre o Projeto

O projeto é um **quiz interativo** com perguntas e respostas, onde o usuário pode testar seus conhecimentos em diversas áreas. Ao final, o sistema calcula a pontuação do usuário com base nas respostas corretas.

## ⚙️ Funcionalidades

- ❓ Perguntas com múltiplas opções de respostas
- 📝 Calcula a pontuação do usuário no final
- 🎯 Feedback sobre o desempenho após o quiz

## 🛠 Tecnologias Utilizadas
- **JavaScript** (para a lógica do quiz)
